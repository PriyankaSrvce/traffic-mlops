# Model Results

## Evaluation setup

Target: continuous `Traffic Volume` (same-day daily observation).
The time-aware holdout is the primary score; the random split is a comparison only.
OneHotEncoder is fit inside each training pipeline, with unseen categories ignored.
`weekday_flag` is excluded because it duplicates `is_weekend`.
Environment: Python 3.14.0, pandas 2.3.3, scikit-learn 1.8.0, XGBoost 3.2.0, MLflow 3.16.1.
These metrics describe the adopted local Phase 1 feature and training implementation. They are not a reproduction of the pre-adoption GitHub clone pipeline, which used a different feature schema and training code. The local baseline report records Python 3.14.0 and scikit-learn 1.8.0; the project requirements pin scikit-learn 1.7.2.
The saved model is a Python serialization artifact; load only this project's trusted output.

Time split cutoff: 2024-02-01.
Train: 2022-01-01 to 2024-01-31 (7145 rows, 761 dates).
Test: 2024-02-01 to 2024-08-09 (1791 rows, 191 dates).

Feature generation in the scratch copy produced 8,936 rows and 12 columns with no missing values; the target was numeric, finite, and nonnegative. The scratch command `python -m src.models.train` completed with exit code 0. Its model loaded and produced 32 finite predictions; MLflow recorded six finished runs. The run output and generated scratch report are the available evidence; no separate console-log file was saved. The original local report and model artifacts were not regenerated by the scratch run; its outputs stayed in the separate scratch workspace. RMSE and MAE are in the target's units, which are unspecified; R² is unitless.

The current code selects the model with the lowest RMSE on this chronological test split. Because the test split also informs model selection, it is not a fully untouched final evaluation. Future model selection should use a separate validation set and reserve the test set for final evaluation.

Scratch-saved model: **Linear Regression** (lowest RMSE on the time-aware holdout).
This is a holdout benchmark, not a claim of future deployment performance.
The dataset has daily same-day weather and no queue-length or signal-phase target.
