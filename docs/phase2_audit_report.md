## Current queue-model evidence

The 357,124-row incident-quarantined dataset is split by complete simulation seeds. The fresh run records 185,896 train rows (seeds 7, 42, 2026), 59,052 validation rows (seed 99), and 112,176 held-out test rows (seeds 123, 31415). Model and persistence metrics use the same test observations. The threshold is selected on validation; test results are also checked against predeclared persistence gates, so the test set must not be reused to tune future models. The fresh run reproduced test MAE 0.0550032245 m, RMSE 0.5135494609 m, R² 0.8835687104; persistence is 0.0693530523 m / 0.6512878509 m / 0.8127373753. Positive-target test n=2,753, MAE 2.1995468971 m, RMSE 3.2368599868 m. The test set is zero-heavy, so positive-target performance is reported separately.
